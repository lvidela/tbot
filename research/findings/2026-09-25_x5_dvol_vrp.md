# Finding X5: the BTC variance risk premium (Deribit DVOL − realised vol) does not predict crypto returns; a VRP timing rule loses to its static-exposure control

**Date:** 2026-09-25 ~23:35Z. The pre-registration says 2026-09-26 in error; the clock was
2026-09-25. · **Author:** Research Agent (cloud) · **Branch:** `research/x5-dvol`
**Label: NEGATIVE** for the registered hypothesis: the primary slope has the wrong sign in
discovery and is null in the holdout. **Power caveat:** the MDE is 13–17% of 28-day return per SD
of VRP, so only very large effects were excludable.

## Question
Does option-implied information, the BTC variance risk premium (VRP), predict 28-day LINK, BTC or
market returns? Would a VRP-based LINK/USD exposure rule beat hold-LINK and a static-exposure
control?

## Hypothesis (pre-registered)
`research/x5_dvol/PREREGISTRATION.md` (`dd79f67`) was committed before any DVOL download.
Discovery was committed (`bc420fa`) before the holdout was run.
- **Primary:** slope of LINK fwd 28d log return on z(VRP) > 0.
- **Family:** 4 tests, Bonferroni α = 0.0125.

## Data sources / period / timestamps
- **Deribit** public `get_volatility_index_data`, BTC and ETH, daily: 2,012 points,
  2021-03-24 → 2026-09-25, fetched 2026-09-25 23:28Z (`research/x5_dvol/data/`).
- **Coinbase** BTC-USD and LINK-USD daily.
- **EW universe:** X1's survivorship-free Binance panel.
- **Timing:** DVOL is lagged one day. The z-score is expanding and uses past values only
  (≥ 180 days).
- **Windows:** 29 non-overlapping 28-day windows in discovery (2021-10 → 2023-12) and 35 in the
  holdout (2024-01 → 2026-08).

The timing rule lost to the no-timing control in both periods. Holding less LINK helped in these
falling-LINK windows, but the static control captured all of that; the timing added nothing.

## Comparison vs hold-LINK and hold-USD
In these windows hold-USD > static > hold-LINK > VRP timing. The static-over-hold gain is the de-risking effect R12 documented, and it depends on the sample's LINK drift. It is not a signal.

## Limitations
- DVOL starts in 2021, so there are only 64 windows in total.
- Only BTC VRP was used (no LINK options exist).
- One market-wide state, so few independent regimes.

## Conclusion
Option-implied volatility adds no detectable information about 28-day crypto returns in
2021–2026, and a VRP exposure rule is dominated by static exposure. This closes the last untested
*kind* of market-timing state on the backlog (price, trend, realised vol, funding, and now
implied vol).
